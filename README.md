# Ace Is Back! True Tales
A non-commercial pop-art comic fan series of Ace Frehley's wildest *true* stories. Live: https://hatlem72-creator.github.io/ace/

- `issues.json`: all issue data (only sourced stories). Run `python3 build.py` to regenerate `issues.js` and the static `issue-N/` pages.
- `make_images.py`: converts raw art in `img-src/` into web images + 1200x630 share images in `img/`.
- Poll + visitor counter use Abacus (abacus.jasoncameron.dev), no cookies.
